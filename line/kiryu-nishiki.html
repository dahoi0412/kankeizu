桐生きりゅうと錦にしき

縁切りの一言だけ先に出す。なぜ、撃てなかった男が切る側に回り、その先で罪を被るのか。

  1. 再会
    0
    待ち合わせ。遅れたのは桐生のほうだった。関係は、まだ信頼のまま。
    「とりあえず飲みに行こうぜ　久々にオールで付き合えよな」
  2. 組抜けを止める
    0
    風間を守るため、桐生は組を抜けようとする。錦は止める。まだ同じ側に引き戻す。
    「車回してくれ錦」
  3. 関係ない
    0
    阿波野の前で、錦は他人を装う。切れ始めたのではなく、守るための他人。
    「錦山関係ねー」
  4. 最後の救出
    0
    公には他人だった二人が、ここで最後に助ける。
    「これがお前を助けてやれる最後だ」
  5. ひと思いに
    0
    助けた直後に、銃を向ける。助けることと、殺すことが同じ口から出る。
    「ひと思いに死なせてやれる　今俺にできんのは　それくらいしか……！」
  6. 撃てない
    0

    0

  9. 並んで歩く
    0

  10. 控えろ錦
    極
    極のセレナ。まだ同じ店に座っている。控えろ、錦。
    「控えろ錦」
  11. 一人で助けに
    極
    堂島が由美をさらう。錦が先に走る。
    「錦が一人で由美を助けに」
  12. 撃っちまった
    極
    錦が撃つ。桐生は逃げろと言う。切った男が、罪を被る。

  13. 誰かをかばってる
    極
    伊達は、誰かをかばっていると言う。公には桐生がやった。
    「誰かをかばってるんです」
  14. 昔の人じゃない
    極
    10年後。真司が言う。錦は、もう昔のあの人ではない。
    「錦のおじきはもう昔のあの人じゃなくなっちまったんです」
  15. 10年ぶりだ
    極
    10年ぶりに飲む。まだ兄弟と呼ぶ。この直後、切る。
    「久しぶりだな」
  16. 今日限り兄弟じゃねえ
    極
    『0』では桐生が切った。ここでは錦が切る。もう一度一緒にやりたかった。
    「もう一度一緒にやりたかった」
    映像を見る
  17. 決着をつけよう
    極
    10年前には戻れない。決着をつけよう。
    「だから決着をつけよう」
  18. もうみんないない
    極
    由美も錦も、風間も。もうみんないない。
    「ユミも錦も風間のおやっさんも」

『0』では並んで歩いた。極では、由美も錦も、もういない。切れなかった線の行き先が、ここまで。
